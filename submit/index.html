    Review & generate

    The files are validated against the same schema.json the repository CI uses. Generating shows a step-by-step GitHub checklist, submissions are reviewed by the maintainers, most are merged within a few working days.

    Your submission files are ready

    Follow the checklist to open one pull request on TheThingsNetwork/lorawan-devices, GitHub forks the repository for you, no local tools needed. The community reviews every submission before it is published.
