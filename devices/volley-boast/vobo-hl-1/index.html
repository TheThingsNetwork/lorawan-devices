About this device

General purpose LoRaWAN bridge certified for use in Class 1 Div 2 hazardous locations

The VoBo-HL-1 - Input Endpoint supports 4 regional frequency plans and operates as a Class A LoRaWAN device. A payload codec is published in the repository, so uplinks are decoded automatically when you onboard it to The Things Stack.

Key features

  • Sensors: 4-20 ma, analog input, battery, button, digital input, voltage.
  • Payload codec included, uplink decoder ready for one-click activation.
  • 4 frequency plans supported: AS923, AU915-928, EU863-870, US902-928.
  • Battery powered (LSH20 (D size)), user replaceable.

Manual setup

1

Create an application

In The Things Stack console, go to Applications → Create application and pick a unique application ID.

2

Register an end device

Choose From the LoRaWAN Device Repository and search for “VoBo-HL-1 - Input Endpoint”. Select your firmware version and frequency plan.

3

Enter device credentials

Provide the DevEUI, JoinEUI and AppKey printed on the device label or QR code.

4

Power on & verify uplinks

Within a few minutes you'll see the join request and decoded uplinks in the Live data tab.
