About this device

The Browan Ambient Light Sensor integrates an optical sensor providing measurements of ambient light intensity which matches the human eye’s response to light under a variety of lighting conditions. It utilizes LoRaWAN® connectivity to transmit data.

The Ambient Light Sensor supports 2 regional frequency plans and operates as a Class A LoRaWAN device. A payload codec is published in the repository, so uplinks are decoded automatically when you onboard it to The Things Stack.

Key features

  • Sensors: light.
  • LoRa Alliance certified, verified interoperability with The Things Stack and other LoRaWAN network servers.
  • Payload codec included, uplink decoder ready for one-click activation.
  • 2 frequency plans supported: EU863-870, US902-928.
  • Battery powered (3.6V 1⁄2 AA Li-SOCl2 1200mAh), user replaceable.

Manual setup

1

Create an application

In The Things Stack console, go to Applications → Create application and pick a unique application ID.

2

Register an end device

Choose From the LoRaWAN Device Repository and search for “Ambient Light Sensor”. Select your firmware version and frequency plan.

3

Enter device credentials

Provide the DevEUI, JoinEUI and AppKey printed on the device label or QR code.

4

Power on & verify uplinks

Within a few minutes you'll see the join request and decoded uplinks in the Live data tab.
