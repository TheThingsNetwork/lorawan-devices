About this device

Multi-variable sensor with differential pressure 0–0.5"wc and wet/wet differential pressure 0–50 PSI

The WM-DP01-W050-0000 Wireless Multi-Variable Sensor supports 1 regional frequency plan and operates as a Class A LoRaWAN device. A payload codec is published in the repository, so uplinks are decoded automatically when you onboard it to The Things Stack.

Key features

  • Sensors: battery, pressure.
  • Payload codec included, uplink decoder ready for one-click activation.
  • 1 frequency plan supported: US902-928.
  • Battery powered (2x CR123A).

Manual setup

1

Create an application

In The Things Stack console, go to Applications → Create application and pick a unique application ID.

2

Register an end device

Choose From the LoRaWAN Device Repository and search for “WM-DP01-W050-0000 Wireless Multi-Variable Sensor”. Select your firmware version and frequency plan.

3

Enter device credentials

Provide the DevEUI, JoinEUI and AppKey printed on the device label or QR code.

4

Power on & verify uplinks

Within a few minutes you'll see the join request and decoded uplinks in the Live data tab.
